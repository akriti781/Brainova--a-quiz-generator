# AI Quiz Generator

An AI-powered quiz generator web application built using FastAPI and Gemini AI.

## Features

- Generate AI-based MCQ quizzes
- Dynamic question generation
- FastAPI backend
- Interactive frontend
- JSON API responses

## Technologies Used

- Python
- FastAPI
- Gemini AI
- HTML
- CSS
- JavaScript

## How to Run

### Backend

```bash
uvicorn main:app --reload
```

### Frontend

Open `index.html` in browser.
